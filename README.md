# 颗粒合成演奏台 · Granular Instrument

一个基于 Web Audio `AudioWorklet` 的颗粒合成声音装置。它从短样本中按指定位置生成多个
加窗片段，每颗颗粒独立保存读取状态与窗包络，通过时长、读取速度、密度与空间分布得到连续
的声音。所有调度以**样本帧**为基准，音频回调只负责按固定量子取数，界面只读取遥测。

## 运行

```bash
npm install
npm run dev            # http://127.0.0.1:5173
npm run test           # 引擎单元测试（Vitest，离线渲染）
npm run test:e2e       # 浏览器端到端测试（Playwright + 真实 AudioWorklet）
npm run build          # 生产构建
```

首次运行 e2e 需要浏览器：`npx playwright install chromium`。无桌面依赖的环境可能还需
要系统库（NSS/NSPR/GTK 等）；可通过 `LD_LIBRARY_PATH` 指向本地解包的库目录。

## 演奏控制面板

浏览器界面（`index.html`）是演奏控制面板，不是 CLI 的替代：

- **素材**：内置脉冲、稳定音、短瞬态三种短样本，也可拖入本地音频（自动转单声道）。
- **边缘政策**：`截取 CLIP`（颗粒限制在样本内，必要时缩短时长，读取永不越界）与
  `循环 LOOP`（颗粒按读取速度在样本内回绕，回绕单独计数）。
- **演奏参数**：密度、颗粒时长、时长抖动、读取速度、速度抖动、读取位置、位置散布、
  立体声展开、颗粒增益、主输出、随机种子——全部在音频线程即时生效。
- **结果区**：声音连续性、RMS 包络、波形、活动颗粒视图、颗粒分布直方图、边界/越界/非
  有限样本/丢弃/限幅/回调异常等指标，以及由实际运算驱动的验收检查与引擎提示。

## 架构

```
src/grain/engine.ts        纯 DSP 引擎（可在 Node 中离线渲染，无 DOM 依赖）
src/grain/materials.ts     三种内置素材与解码
src/grain/types.ts         参数、统计、默认值
src/worklet/grain-processor.ts  AudioWorklet 封装：消息、统计上报、录音搬送
src/main.ts                控制台逻辑：AudioContext、参数同步、录音、WAV 导出
src/ui/panel.ts            滑杆与按钮绑定
src/ui/draw.ts             Canvas 绘制（源波形、RMS、示波、颗粒视图、直方图）
```

### 调度：以样本时刻为准

- 引擎维护 `frame` 样本计数与 `nextSpawnFrame` 触发网格。每次触发后按
  `sampleRate / density` 推进，并做 ±12% 抖动，同时受最小触发间隔约束。
- 音频回调把一次 `process()` 拆成"触发 / 渲染"交替的区间，颗粒在其**精确样本**开始，
  因此块长度变化（64…1024）不会改变平均密度。单元测试覆盖多种块长与中途变块。
- 界面通过 `requestAnimationFrame` 只做绘制；即使停止 rAF（模拟隐藏或冻结窗口），
  Worklet 仍按音频时钟推进并上报统计。暂停仅停止触发并淡出，`frame` 继续前进，恢复时
  时间线按样本帧继续。

### 有界声部池与能量控制

- 固定容量 `220` 个颗粒槽位；池满时新颗粒被丢弃并计入 `dropped`，不会无界增长。
- 每颗颗粒使用 Hann 窗（`sin²`），起止样本窗值为 0；`windowEdgeMax` 统计首末样本的窗
  值，用于验证窗边界归零。
- 重叠能量按功率归一：`normGain = 1 / sqrt(max(0.75, density × duration))`，因此峰值随
  密度增加保持有界；输出再过一道前馈式限幅器（阈值 0.89，释放 120 ms），并记录最大衰减。
- 截取政策下，若颗粒按读取速度会越过样本末尾，则缩短颗粒长度；无法缩短到 ≥4 帧时跳过并
  计数。任何情况下读取位置都钳制在 `[0, len-1]`，越界读取与非有限样本分别计数。

## 测试覆盖

单元测试（`tests/engine.test.ts`、`tests/audioquality.test.ts`）驱动真实引擎：

- 密度与块长无关；中途改变量子大小仍保持平均密度；
- 截取/循环两种边缘政策：无越界读取、窗边界 < 1e-5、循环回绕计数、无 NaN；
- 池容量上限与丢弃计数；峰值不随密度无界增长；
- 暂停期间样本时间继续前进、恢复后重新触发；
- 连续性：密集云 > 95%，稀疏云 < 80%；
- 录音仅包含真实输出并可完整取出；
- 输出无爆音（相邻样本差有界）、无直流偏置。

端到端测试（`tests/e2e/console.spec.ts`）在真实浏览器里驱动界面与 AudioWorklet：
播放、密度滑杆改变实测密度、暂停/恢复、无 rAF 时仍推进、录制并产出可下载 WAV、
极端参数无异常、切换素材与边缘政策。

## 已知边界

- 实时监听质量取决于宿主音频设备；无音频设备的无头环境仍会推进引擎时钟与遥测。
- 录音上限 60 秒，超出部分被丢弃并在统计中标记 `recordDropped`。
- 循环政策下颗粒回绕是刻意的读取方式（并非越界读取），回绕次数单独计数。
